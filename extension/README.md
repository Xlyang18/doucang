# 豆藏 · 商品采集扩展

把淘宝 / 天猫 / 京东商品页的标题、价格、规格、详情送到**本机**的豆藏应用里，之后在豆藏「豆子 → 链接导入」里直接选用。

## 安装（Chrome / Edge）

1. 打开浏览器扩展管理页：地址栏输入 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择这个 `extension` 文件夹（也就是本文件所在的目录）
4. 固定到工具栏，图标出现即安装完成

## 使用

1. 先打开 **豆藏** 应用（它会在本机 `127.0.0.1:47823` 起一个只对内网可访问的服务）
2. 浏览器里打开商品页
3. 三种方式任选：
   - 点工具栏的豆藏图标
   - 快捷键 `Alt + Shift + D`
   - 页面右键 →「发送到豆藏」
4. 回到豆藏 → 豆仓 →「链接导入」→ 面板下方的「来自浏览器扩展的采集」里点「使用」

## 隐私

- 只请求 `127.0.0.1` 和三类商品域名，不含任何第三方服务
- 采集内容只写进本机 `~/Library/Application Support/豆藏/clips.json`
- 关闭豆藏应用时扩展会提示「连不上」，不会缓存到别处
